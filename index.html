Import straight into your Urable account — customers and their vehicles. You'll need an API key: in the Urable app go to Settings → Developer → API Keys → Create API key (admin account required; grant customers:write and items:write scopes), then paste it here.

Before you start a jobs import
  1. Turn off automated scheduled messages and deactivate workflows in the account. A bulk import creates hundreds of jobs at once, and any workflow watching for new or completed jobs will fire on every one of them — real messages to the shop’s real customers.
  2. Run the import.
  3. Consider a workflow on Completed → send payment request to sweep up imported jobs that still owe money, since they bypassed the normal flow.
  4. Turn scheduled messages and workflows back on.
